### 🛡️ ROS2-based Intelligent Collaborative Explosive Disposal Robot System
**ROS2 기반 지능형 협업 폭발물 해체 로봇 시스템**

- **주요 기능**: YOLO 기반 폭발물 및 상자 상태 탐지, 모방학습 기반 상자 개방, RAG·LLM 기반 해체 절차 제공, ROS2 다중 로봇 자율주행
- **기술 스택**: `Python`, `ROS2`, `Nav2`, `YOLOv26m`, `OpenCV`, `PyTorch`, `RAG`, `LLM`
- **담당 역할**: 상황별 데이터셋 구축, 객체 탐지 모델 최적화, 이미테이션 러닝, RAG 기반 LLM 통합, WafflePi 자율주행 및 객체 추종 구현
- **성과**: YOLOv26m 기준 `mAP50-95 95.21%`, `Recall 99.71%`, `Precision 99.91%` 달성 및 3대 로봇 협업 시나리오 구현
